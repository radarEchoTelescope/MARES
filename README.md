This branch is focused on setting up MARES for RET-CR simulations. To this end, it currently has the following features implemented:
* Electric field output 
* Ideal dipole antenna gains
* IceRayTracing, set to a Greenland double exponential ice model
*  In-ice cosmic ray cascades (parameterised footprint method)

Future updates in progress include a FAERIE cascade mode, tabulated antenna models, and an example RET-CR config file detailing the deployed experiment parameters.
